-------------------------------------------------

file nuovo ma NON cancella il vecchio: se resta, Hugo trova due pagine per
lo stesso indirizzo. In PowerShell, dentro C:\Hugo\puntowebferrara-hugo :

  git rm content/sottosopra.md

Poi scompatta lo zip e controlla con git status.
